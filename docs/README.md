# docs/

Supporting documentation that does not fit in the README:

- `dicionario.md` -- the column dictionary, generated from
  `src/vra/registry.py` (never hand-edited; see `CLAUDE.md`).
- `data-availability.md` -- the full Data Availability Statement, source by
  source (the README's "Data availability" section summarises it).
- `declared-differences.md` -- the full list of divergences against the
  original article and the private benchmark (the README's "Declared
  differences" section summarises it).
- `notes/` -- research notes in Portuguese (see `docs/notes/README.md`).
- `tutorial/` -- a didactic walkthrough in Portuguese (see
  `docs/tutorial/README.md`).

`dicionario.md`, `data-availability.md` and `declared-differences.md` do not
exist yet -- they land with the phases that give them something real to
say (see `ROADMAP.md`); this file documents the layout ahead of the
content so later work has a fixed place to go.
