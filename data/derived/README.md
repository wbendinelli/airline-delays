# data/derived/

On-demand aggregates of the canonical flight table at grains other than the
committed `group x route x month` fact table -- route-day, route-week,
city-month, and similar, produced by `aggregate()` in `src/vra/` (see
`DECISIONS.md` ADR-0004). Nothing here is a second source of truth: every
table is a tested, additive projection of the flight table, regenerated by
running the aggregation again, never hand-edited.

Git-ignored except for this README (see `.gitignore`): these tables exist
only as long as someone needs that particular grain locally.
